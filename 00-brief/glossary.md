# Glossary

Status: draft — YYYY-MM-DD

Define terms once so the brief, program, operations, and financial documents use them identically.

| Term | Definition in this project |
|---|---|
| Key | One rentable guestroom unit, regardless of bay count |
| Bay | Structural module width that one standard room occupies |
| Superficie construida | Built area measured per the municipal ordinance; the planning (edificabilidad) figure |
| Superficie útil | Usable floor area measured to the inside face of partitions; the tourism-regulation figure |
| PEM / PEC | Presupuesto de Ejecución Material / por Contrata |
| Suelo rústico | Rural land class under Castilla y León land law; hotel use requires authorization |
| DO | Denominación de Origen (wine appellation); parts of Soria fall within DO Ribera del Duero |
| Estrellas | Hotel category under the regional tourism regulation |
| BOH / FOH | Back of house / front of house |
| F&B | Food and beverage outlets |
| FF&E | Furniture, fixtures, and equipment |
| OS&E | Operating supplies and equipment |
| ADR / RevPAR / GOP | Average daily rate / revenue per available room / gross operating profit |
| Comp set | Competitive set of hotels used in `01-market/competitive-set.md` |
| Vendimia | Harvest; the winery's peak operating period and a traffic and noise event on site |
